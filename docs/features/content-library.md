# 内容库：对话、短文与单词表

> 本轮迭代新增的四个学习者入口：多角色对话、短文、单词表与单词详情。内容全部来自权威库中的句子/对话/短文与概念词典；界面文案来自本地化数据层。

## 多角色对话页

- 路由：`/dialogues`（列表）与 `/dialogues/{dialogueId}`（详情）。
- 列表按对话 ID 展示每个对话及首行台词预览；详情按原始行序显示说话人标签与台词。
- **整段播放**：按行顺序逐行播放，每行使用自己的 `VoiceRole` 音频，形成多角色对话效果；行与行之间不朗读说话人标签。
- **单句播放**：每行独立提供播放按钮，可只播放指定语句。
- 台词中的词/短语可点击打开点词弹层（与课程内句子一致）。

## 短文页

- 路由：`/essays`（列表）与 `/essays/{essayId}`（详情）。
- 短文是一组有序句子的逻辑组合，**没有独立的 TTS 文件**：整篇播放由各句音频按顺序串联完成。
- 详情页提供整篇连续播放与逐句播放；句中单词/短语可点击查看注释。
- 列表以首句作为预览标题。

## 单词表与单词详情

- 路由：`/vocabulary`（单词表）与 `/vocabulary/{conceptId}`（详情）。
- 单词表数据来自客户端概念词典 K-V 缓存（`dictionary.json`），不引入新的逐词服务端往返。
- 每页显示数量可选 **15 / 20 / 30**；分页在客户端完成，切换每页数量或释义显隐均不丢失当前页。
- “显示注释信息”开关统一控制基础语言释义、词性、CEFR 等辅助信息；关闭后只显示目标语言主词元，便于自测。
- 点击单词进入详情页：目标语言主词元（名词含冠词）、词性、基础语言释义、完整形态变化表、单词音频。
- 详情页“例句”区域列出权威内容库中**明确标注了该概念**的句子（词 ↔ 句互链）；每条例句可播放句子音频，句中词仍可点击。

## 数据供给

- 对话/短文/例句经内容模块只读查询下发（`GET /api/content/dialogues`、`/api/content/essays`、`/api/content/sentences`）。
- 句子分词中的 `conceptKey` 是发布期消歧后的稳定概念引用；例句检索只使用该引用，不依赖模糊表面字符串匹配。
- 句子的默认音频角色为 `Female`，对话行使用行自身 `VoiceRole`；音频相对路径由服务端按 `audio-asset-spec.md` 解析，客户端统一经 `MediaUrlResolver` 拼接基路径。

## 完整 A1 课程规模（当前种子）

| 内容 | 数量 |
|---|---|
| 单元 | 5 |
| 课时 | 30（每课时恰好 6 道题，覆盖六种题型） |
| 概念 | 300（名词 160、动词 60、形容词 34、短语/功能词 46） |
| 例句 | 600（每概念 2 条，含中文对照与词元标注） |
| 对话 | 30（每课时一个，3 行、三种音色） |
| 短文 | 15（每两课一篇） |
| 习题 | 180（每课时 6 题） |
| 音频资产 | 每概念 × 3 音色 + 每句 × 3 音色（约 2700 个文件） |

- 概念按单元主题排列：问候与人物、饮食、家庭与居家、城市与出行、学习与日常。
- 每个概念至少关联 2 条例句；句中其余已收录词按表层形式自动标注（歧义表层跳过，避免误链）。
- 短语概念没有形态范式：句子与习题只记录概念键（ADR 相关校验放宽），词↔句互链仍按概念键查询。
