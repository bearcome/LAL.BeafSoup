# 平台上线就绪度自审

> 评审时间：2026-11-14（同日更新：账户生命周期与完整 A1 课程已实现）。范围：当前 `dev` 分支已实现能力与"可公开上线运营的语言学习平台"之间的差距。结论用于排期与决策，不是对现有功能的否定。

## 0. 本次补强（2026-11-14）

- **账户生命周期（ADR-008）**：邮箱验证（登录门禁可配置）、密码找回、账户注销（删除个人数据）、数据导出、隐私政策与服务条款页面、数据保留期清理命令均已实现并有测试覆盖。
- **完整 A1 课程内容**：300 个概念（名词/动词/形容词/短语）、600 条例句、30 个对话、15 篇短文、180 道习题、30 个课时（5 个单元），每个概念至少 2 条例句；音频按需生成。
- 因此原先的 P0.1（内容规模）与 P0.3（账户生命周期/合规功能）从"缺口"转为"已完成功能"，剩余 P0 见下。

## 1. 结论摘要

**当前形态：功能完整的封闭 Beta / 内测 MVP，尚未达到公开上线运营标准。**

- 学习闭环、账户隔离、六种题型、FSRS 复习、点词形态学、内容库（对话/短文/单词表/例句）、预生成音频、亮暗主题与响应式均已可用，并通过领域测试、持久化测试、API 集成测试与手工端到端验证。
- 距公开上线的主要缺口不在"再做一个页面"，而在：**内容规模与教学完整性、考试与能力认证、账号生命周期与合规、运维可观测性与备份、自动化端到端质量门禁、内容授权**。
- 建议先以"邀请制封闭 Beta"验证留存与学习效果，同时并行补齐 P0 项；P0 全部关闭后再开放注册。

## 3. 上线缺口（按优先级）

### P0 — 公开上线前必须完成

1. ~~**教学内容规模与课程完整性**~~（本轮已完成 A1 全量）
   - 已交付 300 概念 / 30 课时 / 每概念 2 例句；仍需随后续迭代评估 A2 与更系统的复习编排。
   - 仍缺：能力分级矩阵（A1–C1 覆盖率）、单元目标/先修关系的显式建模。

2. **模拟考试与能力认证**
   - Exam 模块尚未实现（第 5 阶段）；SCENARIO 中的歌德/telc 风格整卷、计时、分数映射缺失。
   - Q4（题库来源与授权）仍未决策；在授权明确前不得使用官方真题或官方标识。

3. ~~**账号生命周期与合规（功能）**~~（本轮已完成功能层）
   - 已完成：邮箱验证、密码找回、注销（删除个人数据）、数据导出、隐私政策/服务条款、保留期清理。
   - 仍缺（部署与法务层）：生产邮件服务实现（`IEmailSender`）、隐私政策文本的法律评审、未成年人保护策略、登录/注册限流与审计日志、生产 JWT 密钥管理。

4. **运维与可靠性**
   - SQLite 单文件权威库：需自动化备份、恢复演练、磁盘/文件锁监控；多实例部署前需评估并发写入。
   - 仅有 `/health`；缺少结构化日志、指标、错误追踪、告警与发布回滚流程。
   - 缺少 CI 部署流水线与生产配置校验（CORS、API 基址、媒体基址、HTTPS）；保留期清理命令需以定时任务调度。

5. **质量门禁**
   - 当前端到端验证以手工浏览器为主；需要把关键路径（注册→学习→判分→复习→内容库→考试）固化为 CI 中的浏览器自动化测试。
   - 缺少负载/并发测试（登录、判分、复习队列）与安全测试（越权、令牌泄漏、注入、速率限制）。
   - **种子内容与音频目录当前被 `.gitignore` 排除**（`/data/seed`、`wwwroot/media/audio/de-DE`），而种子管线测试依赖它们存在；公开分发前必须确定内容仓库/发布产物的版本化与 CI 获取方式（或改为私有内容包 + 构建期解密）。

6. **内容授权与法务**
   - 德语文本、例句、短文、听力脚本的作者与版权归属需明确；TTS 输出需符合 Azure 服务条款。
   - "Goethe"/"telc" 等名称与题型风格涉及商标与真题授权，必须在宣传与考试模块中审慎处理。

### P1 — 上线后 1–2 个迭代内应补齐

1. **学习效果与个性化**
   - 学习报告：掌握度热力图、薄弱词/形态、听说读写分项、复习命中率。
   - 入学分级测试与动态难度；错题本与"弱项专练"。
   - 反向卡片（释义→单词）在稳定性阈值后出现（文档已有规则，尚未实现）。
   - 语音输出练习与发音评分（ASR）缺失；当前只有"听"和"选/填"，没有"说"和"写"的自由产出。

2. **离线与移动体验**
   - 按 ADR-004 首发不支持离线提交学习结果；PWA 尚未定义音频/词典/课程的离线缓存策略。
   - 需要移动端真机回归（安全区、软键盘、音频自动播放策略、横竖屏）。

3. **可访问性**
   - 需 WCAG 2.1 AA 审计：对比度、焦点顺序、屏幕阅读器语义、减少动效偏好、纯键盘完成一课时。
   - 音频题需要字幕/文字替代方案（可配置），并保证听力题不因无法播放而阻塞。

4. **运营与内容生产**
   - 当前内容通过 JSON 种子 + `DbMigrator` 发布，无后台 CMS、审核流、版本发布/回滚与灰度。
   - 缺少内容质量指标（完课率、错题率、跳出点）与 A/B 实验能力。

5. **第二门语言验证**
   - 目前只有 de-DE 的音色与内容；中文分词处理器未实现（句子 zh-CN 分词为空）。
   - 需要按承诺用已有处理器支持的语言完成一次"纯数据/配置"接入，验证扩展性。

### P2 — 增长与差异化（非上线阻塞）

- 排行榜、好友/社交、装扮商店（MVP 范围外，已在模型中预留扩展缝）。
- 学习提醒/推送、连续学习保护、每周目标。
- AI 口语陪练、写作批改、个性化学习计划。
- 管理后台与运营统计看板（现有统计仅注册/在线/时长）。

## 4. 建议的上线路径

1. **封闭 Beta（当前可进入）**：邀请制；内容已是完整 A1 课程，可直接用于留存与学习效果验证。
2. **公开 Beta 前置**：完成 P0.4（备份/监控/定时清理）、P0.5（自动化 E2E/负载/安全测试）以及 P0.3 的部署层事项（生产邮件服务、密钥管理、隐私政策法律评审）。
3. **公开上线**：完成 P0.2（Exam 模块 + 题库授权）与 P0.6（内容/商标法务）。
4. **上线后**：按 P1 补齐学习报告、离线、可访问性、内容运营与第二门语言。

## 6. 已关闭的缺口

### 上一轮（内容库与音频细化）

- 对话音频只播首行 → 已按行顺序连续播放，每行可单句播放。
- 目标语言选项无读音 → 选中即播放对应词元音频。
- 可点击词无视觉提示 → 链接样式 + 最长短语匹配；词典未命中词保持普通文本。
- 背词仅有卡片流 → 新增单词表（分页/注释显隐）与单词详情（形态 + 例句）。
- 无短文与多角色对话入口 → 新增内容库页面。
- 每种内容仅 3 条示例 → 扩充到每种类型 ≥10 个实例并生成全部音频。
- 习题呈现顺序与课程编排不一致 → 已修复并加 API 测试。

### 本轮（账户生命周期 + 完整 A1 课程）

- 缺邮箱验证/密码找回 → 一次性验证码、限时、错误尝试上限、申请频率限制（ADR-008）。
- 缺账户注销与数据导出 → 设置页注销（密码确认、删除个人数据）与 JSON 导出。
- 缺隐私政策/服务条款 → 本地化的 `/privacy`、`/terms`，含数据类别、保留期与权利说明。
- 缺数据保留期 → `DbMigrator purge`（会话 90 天、令牌 7 天，幂等）。
- 内容仅示例级 → 完整 A1：300 概念、600 例句、30 对话、15 短文、180 习题、30 课时、5 单元。
- 页面刷新后会话在 90 秒租约后被强制登出 → 心跳在回访时自动恢复并立即续租（含单元测试）。
