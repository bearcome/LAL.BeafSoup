# UI 主题与响应式规则

> 需求 7 与 13。

## 主题（亮/暗双色调）

- 单一主题系统：CSS 自定义属性定义在 `:root` / `[data-theme="dark"]` 上；**组件中禁止硬编码颜色**——组件只消费语义令牌。
- 令牌组：`color-surface-*`、`color-text-*`、`color-primary`、`color-success/warning/error`、`color-popover`、`shadow-*`、`radius-*`、`spacing-*`、`font-*`。
- 两套主题的文字与交互元素对比度均须达到 WCAG AA。
- 主题选择：学习者设置（持久化在 `LearnerProfile`），默认跟随系统，手动开关常驻可见。加载时无主题闪烁（内联初始化脚本）。

## 响应式（桌面 + 手机）

- 移动优先 CSS；断点：`<576px` 手机、`≥768px` 平板、`≥1200px` 桌面。
- 布局原语：技能树与仪表盘用 CSS Grid；横条用 flex；习题区最大宽度 `860px` 居中。
- 首页使用最大宽度 `1180px` 的产品网格，首屏由学习行动与“词元—释义—词形”演示卡组成；该演示文案同样来自本地化数据层，不能在 Razor 中硬编码示例文本。
- 主布局负责品牌、导航、主题、会话操作与唯一的学习进度条；页面自身不重复渲染进度。
- 背词卡、评级按钮、表单、空态和错误态共用主题令牌；背词评级在手机端为两列，其他手机布局不得产生横向滚动。
- 手机触摸目标 ≥ `44×44px`；音频按钮单手可触达。音频按钮只显示音频图标，播放状态用呼吸动画表达，失败时才显示本地化短提示；禁止在按钮内堆叠“播放/播放中”等冗长文案。
- 背词页在手机端隐藏页眉副标题与语言角标，标题、卡片内边距和表格行距使用紧凑值，保证单词、变位表与“下一个”按钮在首屏内可见。
- 触屏无悬停依赖（点词弹层用点击触发；见 `word-inspector-popover.md`）。
- 第 3 阶段提供 PWA manifest，手机可"安装"应用。

## 验收场景（第 4 阶段 QA）

1. 桌面端切换主题 → 两套主题均验证，无未令牌化颜色。
2. 375×812（iPhone）与 1920×1080 视口：课时流程、背词、弹层、考试界面均可正常使用，无横向滚动。
3. 屏幕边缘弹层自动翻转/钳制，无布局位移（需求 6）。
