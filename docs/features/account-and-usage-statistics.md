# 账号、权限与使用统计

## 范围与原则

本规范定义注册账户、初期功能开放策略，以及注册数、在线用户数和在线时长的统计口径。客户端保持 Blazor WASM 独立静态部署；身份验证、账户归属校验和权威统计由独立部署的服务端 API 提供。浏览器本地状态只用于界面体验，不能作为统计事实来源。

## 账号与访问策略

- 注册成功后创建稳定 `UserId` 和 `UserAccount`。身份关联在所属提供方范围内唯一，并映射到 `UserId`；账户可关联多个身份提供方。凭据由身份提供方管理，不存入领域对象、学习内容或普通日志。
- 初期所有有效注册账户默认可使用全部普通学习功能，不按普通用户分层，也不要求付费/角色授权。后续限制通过服务端访问策略启用，不在业务代码中散布用户类型判断。
- 账户所有权校验从第一版即启用：请求中的 `UserId` 必须来自经过验证的身份上下文，不能由客户端任意指定。每个账户只能读写自己的学习配置、学习进度、复习卡和考试记录；UI 隐藏功能不构成授权。
- 管理员、运营统计和账户管理能力不属于普通学习权限，服务端默认拒绝。后续以稳定权限标识和策略映射开放，不把管理权限隐含授予注册用户。
- 最大并发会话数由服务端策略配置；初始默认遵循架构约束，每个账户最多一个有效交互会话。会话冲突的处置方式须在身份/API ADR 中确定。

## 用户进度归属

- 一个账户可拥有多个 `LearnerProfile`，分别表示不同基础语言/目标语言组合；每个学习配置、复习卡、进度记录和考试尝试都带有 `UserId` 或其所属 `LearnerProfileId`。
- 已判分的作答、复习和课时完成以不可变学习活动记录；活动有稳定事件 ID，服务端对重试幂等处理，避免重复增加经验、连胜或复习次数。
- `ProgressRecord` 和统计摘要是可重建的状态/投影；课程、题目和考试试卷定义不保存用户进度。
- 只有能明确关联到 `InflectionFormId` 的结果才更新对应 FSRS 卡。句子或听力理解结果可以更新课时/学习活动统计，但不能被推断为某个词形的复习结果。

## 统计定义

| 指标 | 规范口径 | 权威来源 |
|---|---|---|
| 注册用户总数 | 服务端成功接受的非测试 `UserRegistered` 事件数，按稳定事件 ID 去重。停用不减少该累计值；测试/导入账户排除。账户删除后的聚合留存规则须遵守适用隐私要求并由 ADR 明确。 | Identity 注册事务及去重统计投影 |
| 有效账户数 | 查询时状态为有效且非测试账户的唯一账户数；停用/删除账户不计入。 | Identity 账户状态 |
| 在线用户数 | 最近一次有效服务端心跳仍在在线租约内的不同 `UserId` 数；同一用户多个会话最多计一名在线用户。 | 服务端会话租约投影 |
| 在线会话数 | 在线租约内的不同 `SessionId` 数，作为在线用户数的辅助诊断指标。 | 服务端会话租约投影 |
| 在线时长 | 每个会话按服务端接受的连续心跳间隔累计；间隔超过配置的最大计时窗口时，不追补缺失时段。按用户、自然日/指定时区及查询周期聚合。 | 服务端会话记录/时长投影 |

在线状态由 `LastHeartbeatAt + SessionLeaseTtl` 判断，心跳周期、租约时长、最大计时窗口均为服务端配置，并由 ADR 固化初始值。服务端使用 UTC 时间；客户端时间戳不参与口径。会话结束时记录服务端时间；客户端关闭页面、断网或进程崩溃不保证发送结束事件，因此最终状态由租约过期收敛。

在线时长表示客户端会话在有效心跳覆盖下的在线时长估算，不表示用户持续注视屏幕或实际学习时长。后台标签页、设备休眠、断网和最后一个心跳后的尾段可能带来测量误差；产品不得将其展示为精确专注时长。过期心跳不能延长在线租约或补记过期区间。

## 可靠性与隐私

- 注册与统计投影更新须可幂等恢复；跨模块事件采用可重试投递与去重，统计故障不得回滚已成功的账户注册或学习活动。
- 在线用户统计不依赖 WebSocket 必须保持连接；心跳与租约构成明确的在线判据。不得仅用页面打开次数或客户端本地计时推断在线状态。
- 只收集实现账户安全、在线判定和聚合统计所需的数据。默认不要求采集原始 IP、精确位置或完整 User-Agent；日志不得包含密码、令牌或可恢复的凭据。
- 运营统计只向有对应服务端权限的操作者提供；普通学习账户不能枚举其他用户或查看个人级会话明细。
- 账户删除、统计保留期、时区口径、匿名化及身份提供方须在上线前由 ADR 和隐私要求确定；在决策前不得承诺永久保留个人级数据。

## 验收边界

- 普通有效注册用户可以访问全部普通学习功能；直接调用 API 访问他人数据必须被拒绝。
- 重放同一注册或学习事件不能重复计数；停用账户从有效账户数中消失，但不改变累计注册数。
- 超过在线租约的会话不计在线；一个用户的多个有效会话在在线用户数中只计一次。
- 缺失或延迟心跳不产生无限时长；超出最大计时窗口的间隔不补记。
- 不存在身份/API 服务或服务端持久化时，注册数、在线用户数和在线时长均标记为不可用，不回退为客户端伪统计。
