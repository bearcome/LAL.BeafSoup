# 题型规格

> 需求 3。所有题型即时判分，完成后向 SRS 调度器与进度系统供数。

## 作答流程

课程、复习和模拟考试中均逐题作答：页面只显示当前题，不展示后续题目。选择题（包括 `DialogueCloze` 的 `Choice` 模式）在选定选项后立即判分；输入题（包括 `DialogueCloze` 的 `Input` 模式）由学习者手动提交后立即判分。

答错时显示错误反馈并留在当前题，允许修改答案后重试；每次错误尝试按现有规则扣除红心。答对时按正常规则奖励经验，不因此前的错误尝试减少奖励，并自动进入下一题，无需额外点击继续。

| 题型 | 注册表键 | 交互 |
|---|---|---|
| 单词释义选择题 | `WordDefinitionMcq` | 展示单词（带音频，可为某变格形态）；4 选 1 选出基础语言正确释义， 确保只有一个合理答案，不能出现多个选项均正确，允许点击播放音频作为提示|
| 句子填空选择题 | `SentenceClozeMcq` | 句子带空；4 选 1 选出缺失词/短语（选项可悬停/点击查看原型与常用形态），确保只有一个合理答案，不能出现多个选项均正确，允许点击播放音频作为提示 |
| 句子填空输入题 | `SentenceClozeInput` | 同上的空，自由输入；宽容判分（大小写/变音符号不敏感、冠词可配置容忍），按词元判分并高亮错误，允许点击播放音频作为提示 |
| 翻译排序题 | `SentenceTranslationOrder` | 展示基础语言句子，提供其目标语言译句的词块；学习者将全部词块按正确顺序排列 |
| 场景对话听力选择题 | `DialogueListeningMcq` | 播放完整对话音频，回答理解性选择题，支持自动连续播放和留间隔跟读模式播放 |
| 补全对话（对话族内特殊题型，规则见下） | `DialogueCloze` | 对话行中带空；版本化题目负载通过 `responseMode` 指定选择或输入；音频播放**补全后**的行 |

题型注册表共六种：`WordDefinitionMcq`、`SentenceClozeMcq`、`SentenceClozeInput`、`SentenceTranslationOrder`、`DialogueListeningMcq`、`DialogueCloze`。补全对话的选择/输入模式由题目负载指定。`MockExam` 是 Exam 模块的计时整卷编排（A1–C1），组合已注册题型，不是题型注册键；另有独立背单词模块。

## 对话填空——音频规则（需求 8，规范性）

题目展示：`Max: ____!  Kari: Guten Tag!`

- 学习者听到的音频是**用正确答案补全后的完整对话**，每个说话人按其行配置的 `VoiceRole` 合成一行：
  - 第 1 行 TTS 输入：`Guten Tag!`（Max 行角色）
  - 第 2 行 TTS 输入：`Guten Tag!`（Kari 行角色）
- **禁止**：朗读 `Max:` / `Kari:` 标签；播放带静默空或提示音的空行；播放 `A: B: Guten Tag!` 式缺行拼接。
- 实现钩子：生成管线产出 `{sentenceId}-revealed-{assetFileToken}.mp3`（见 `audio-asset-spec.md`）；题型引擎将填空题映射到补全版音频；说话人标签从结构上就不进入 TTS 文本字段。

## 判分惯例

- 选择题：选定选项后即时判分；答错扣红心（体力制），可修改选择并重试；答对加经验值。
- 输入填空：手动提交后，以目标语言配置的规范化规则处理答案（去空白、大小写折叠、变音符号折叠及可配置的冠词容忍），与题目明确列出的**所有可接受形态**比对；不使用未声明的模糊匹配。
- `SentenceTranslationOrder`：题干使用基础语言版本，词块来自同一语义键的目标语言版本。题目负载保存每个词块的唯一实例 ID 和正确 ID 顺序；作答必须将全部词块各使用一次，并与答案顺序完全一致。重复文本是不同词块实例；标点随所属词块显示，不单独排序或判分。
- 听力题：允许重播（可配置上限 3 次），重播不惩罚。
- 每次作答产生 `ExerciseAnswered`（含判分结果）事件，供学习/进度模块消费。

## 各题型正确性验证

| 题型 | 判定正确的依据 |
|---|---|
| `WordDefinitionMcq` | 所选选项的稳定释义引用与题目指定的基础语言释义引用一致；内容发布时确保只有一个正确选项。 |
| `SentenceClozeMcq` | 所选选项的 `InflectionFormId` 或短语引用与空位的正确答案引用一致；不按显示文本猜测，且仅有一个正确选项。 |
| `SentenceClozeInput` | 按已配置的目标语言规范化输入，并与空位明确列出的可接受词形逐一匹配；匹配任一项才正确。 |
| `SentenceTranslationOrder` | 所提交的词块实例 ID 序列与题目负载的正确顺序完全一致，且所有词块各出现一次。 |
| `DialogueListeningMcq` | 所选选项 ID 与理解题负载中的正确选项 ID 一致；音频播放或重播本身不构成答案。 |
| `DialogueCloze`（`Choice`） | 所选选项的词形/短语引用与该空位的正确答案引用一致；题目负载必须提供唯一正确选项。 |
| `DialogueCloze`（`Input`） | 与 `SentenceClozeInput` 相同，按该空位的可接受词形集合及目标语言规范化规则匹配。 |
