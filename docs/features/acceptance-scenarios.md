# 核心验收场景（BDD）

> 本文件是实现与端到端验收的规范性场景。阶段 0 仅维护场景；进入阶段 1 后，将每个场景映射到领域测试、应用/API 集成测试或浏览器端到端测试。新增或改变行为时，先更新场景，再实现。

## 账户与权限

### 注册账户默认拥有学习权限

**Given** 用户未注册，且 Identity/API 服务可用<br>
**When** 用户成功注册并取得经过验证的身份<br>
**Then** 系统创建唯一 `UserId` 和默认 `LearnerProfile`<br>
**And** 该账户可使用全部普通学习功能<br>
**And** 管理员与运营统计权限仍默认拒绝

### 账户数据不能跨用户访问

**Given** 用户 A 和用户 B 均已认证，且 B 拥有学习配置、复习卡和考试记录<br>
**When** 用户 A 通过读取、更新或删除 API 请求访问 B 的任一资源<br>
**Then** 服务端拒绝请求且不泄漏资源内容或是否存在<br>
**And** 将客户端伪造的 B `UserId` 视为无效授权依据

## 学习记录与复习

### 重放作答不会重复记分

**Given** 一次已判分的作答带有稳定 `ActivityId` 并已被服务端接受<br>
**When** 客户端因超时以同一 `ActivityId` 重试提交<br>
**Then** 系统返回该活动的既有结果<br>
**And** 经验、连胜、红心、形态掌握度和 FSRS 状态均不重复变更

### 形态练习更新形态掌握度和概念调度卡

**Given** 一道练习的正确答案已明确关联到 `ParadigmCellId`，且该槽位属于 `ConceptId`<br>
**When** 学习者提交答案并获得判分<br>
**Then** 系统更新该槽位的 `FormMastery`<br>
**And** 以同一判分结果评级该 `LearnerProfileId` 的唯一 `ConceptId` `ReviewCard`<br>
**And** 不为同一概念下的词元或屈折形式另建 FSRS 卡

### 单纯查看词形不产生复习结果

**Given** 学习者打开点词弹层或点击一个词形<br>
**When** 没有发生已判分作答或明确的复习评级<br>
**Then** 系统可以记录必要的非评分分析事件<br>
**But** 不改变 `FormMastery`、FSRS 状态、经验或连胜

## 多语言文本与词元标注

### 标注精确覆盖所引用的翻译版本

**Given** 某句子的 `(SemanticKey, LanguageCode)` 文本修订号为 N<br>
**When** 系统保存该版本的 `SentenceTokenization`<br>
**Then** 词元跨度按 Unicode scalar 索引、无重叠且顺序完整覆盖全文<br>
**And** 标注保存修订号 N，不复制另一份全文

### 文本更新使旧词元标注失效

**Given** 句子词元标注绑定文本修订号 N<br>
**When** 同一语言版本的文本更新到修订号 N+1<br>
**Then** 旧标注不得静默用于渲染、点词或判分<br>
**And** 内容发布必须先重新校验或生成对应标注

### 歧义形式由句子标注消歧

**Given** 相同规范化表层形式可匹配多个 `LexicalConcept` 或 `ParadigmCell`<br>
**When** 词汇解析服务检索该形式<br>
**Then** 返回候选集合而不假定全局唯一<br>
**And** 已发布句子必须将可点选词元明确关联到一个已消歧的形态或短语

### 一个语义对应多个词元且每语言恰一个主词元

**Given** 概念 `concept.drink` 在德语有 `trinken`（主）、`zechen`（非主、语体 Elevated），在中文有 `喝`（主）、`饮`（非主、语体 Literary）<br>
**When** 学习者点词或学习该概念<br>
**Then** 界面以各语言主词元为默认展示（名词 `DisplayWord` 含冠词），非主词元作为同义/语体变体列出<br>
**And** 基础语言解释取基础语言主词元（`喝`），不展示非主词元文本<br>
**And** 同一 `(概念, 语言)` 下不允许出现零个或多个主词元（入库校验拒绝）

## 题型与音频

### 作答时只显示当前题

**Given** 学习者正在课程、复习或模拟考试中作答，且当前题和后续题均存在<br>
**When** 系统展示当前题<br>
**Then** 页面只显示当前这一题，不显示后续题目

### 选择题选项变更时即时判分并自动推进

**Given** 学习者正在回答一道选择题，且后续题存在<br>
**When** 学习者选定一个选项<br>
**Then** 系统立即判分<br>
**And** 若答错，显示错误反馈、按现有规则扣除红心并留在当前题，允许修改选项重试<br>
**And** 若最终答对，按正常规则奖励该题经验，不因之前的错误尝试减少奖励<br>
**And** 答对后系统自动显示下一题，无需额外点击继续

### 输入题手动提交后判分并自动推进

**Given** 学习者正在回答一道输入题，且后续题存在<br>
**When** 学习者手动提交答案<br>
**Then** 系统立即判分<br>
**And** 若答错，显示错误反馈、按现有规则扣除红心并留在当前题，允许修改答案重试<br>
**And** 若最终答对，按正常规则奖励该题经验，不因之前的错误尝试减少奖励<br>
**And** 答对后系统自动显示下一题，无需额外点击继续

### 选择题按题目负载的正确答案引用判分

**Given** 一道 `WordDefinitionMcq`、`SentenceClozeMcq`、`DialogueListeningMcq` 或 `DialogueCloze`（`Choice`）题已定义唯一正确答案引用<br>
**When** 学习者选择一个选项<br>
**Then** 仅当选项的稳定引用与题目负载中的正确答案引用一致时才判为正确<br>
**And** 不以可能歧义的显示文本代替答案引用进行推断

### 输入填空按可接受词形集合判分

**Given** 一道 `SentenceClozeInput` 或 `DialogueCloze`（`Input`）题已声明目标语言、规范化规则和可接受词形集合<br>
**When** 学习者手动提交答案<br>
**Then** 系统按声明的规范化规则处理输入，并与可接受词形逐一匹配<br>
**And** 仅匹配其中一项才判为正确，不进行未声明的模糊匹配

### 翻译排序题要求词块顺序完全正确

**Given** 一道 `SentenceTranslationOrder` 题以基础语言句子为题干，并提供同一语义键目标语言译句的词块<br>
**When** 学习者提交排列结果<br>
**Then** 只有所有词块各使用一次且实例 ID 顺序与题目负载中的正确顺序完全一致时才判为正确<br>
**And** 即使重复词块显示文本相同，也按不同实例分别校验

### 对话填空按题目负载选择作答模式

**Given** 一道 `DialogueCloze` 题的 `responseMode` 为 `Choice` 或 `Input`<br>
**When** 题目交给题型注册表处理<br>
**Then** 对应 handler 按该模式校验答案和判分<br>
**And** 未知模式或不兼容的负载版本在发布/加载时明确失败，不静默退化

### 补全对话音频不朗读说话人标签

**Given** 对话题存在正确答案、空行和多名说话人<br>
**When** 生成或选择补全版音频<br>
**Then** 音频按原对话顺序包含补全后的所有有效台词<br>
**And** 每行使用自己的 `VoiceRole`<br>
**And** 不朗读说话人标签，不生成缺行或空白占位音频<br>
**And** 补全版资产缺失时回退到同句子的完整句音频，不显示播放错误

### 名词单词音频带冠词朗读

**Given** 一个带冠词的名词词元（如 `Kaffee`，冠词 `der`）<br>
**When** 生成或播放该单词音频<br>
**Then** TTS 文本为 `冠词 + 空格 + 词元`（即 `der Kaffee`），音频包含冠词发音<br>
**And** 无冠词名词及动词、形容词等其他词性的单词音频仅朗读词元本身

## 界面、背词与静态音频

### 首页以本地化学习入口和真实产品特色呈现

**Given** 学习者打开首页，且界面文案目录与概念词典可用<br>
**When** 首页在桌面或手机视口渲染<br>
**Then** 首屏提供课程与背词入口，并通过词元、基础语言释义及词形展示产品的形态学能力<br>
**And** 所有可见文案来自本地化数据层，亮/暗主题均无横向滚动且键盘焦点可见

### 背词页首次打开即可学习或给出明确状态

**Given** 学习者已认证、学习配置可读取，且概念词典存在可加入的概念<br>
**When** 学习者打开背词页且当前没有到期卡片<br>
**Then** 系统在每日新卡预算内自动加入新卡并显示第一张卡片<br>
**And** 不在布局与页面中重复显示学习进度<br>
**And** 词典或队列加载失败时显示本地化错误与重试入口，不无限加载、不留下未处理异常

### 背词卡加载后自动播放单词音频

**Given** 当前背词卡的目标语言主词元提供单词音频<br>
**When** 卡片在页面中显示或切换到下一张卡片<br>
**Then** 该卡片的单词音频自动播放一次，同一张卡不重复自动播放<br>
**And** 浏览器拒绝自动播放时保持静默，不显示播放失败提示，学习者仍可手动播放

### 背词卡以单个“下一个”按钮推进

**Given** 学习者已翻面查看当前背词卡的释义与形态变化<br>
**When** 学习者点击“下一个”<br>
**Then** 系统以 FSRS 评级 `Good`（3）记录本次复习，并显示下一张到期卡片<br>
**And** 页面不提供 `Again / Hard / Good / Easy` 难度选择

### 德语动词形态变化以人称×时态表格显示

**Given** 当前背词卡的目标语言主词元为动词，且携带完整变位范式（如 `indicative_present`、`indicative_past`、`indicative_perfect`）<br>
**When** 学习者翻面查看形态变化<br>
**Then** 表格列头依次为人称 `ich`、`du`、`er/sie/es`、`wir`、`ihr`、`sie/Sie`，行头为本地化的时态名（现在时、过去式、现在完成时）<br>
**And** 每个单元格显示对应范式槽位的形式<br>
**And** 非动词范式（如名词 `declension`、形容词 `comparison`）保持分组平铺展示<br>
**And** 手机视口下表格紧凑显示，不产生页面横向滚动

### 音频由可配置基路径解析到客户端静态资产

**Given** 音频生成工具使用 `media/audio/` 作为客户端静态资源目录，词典或习题提供 `{language}/{name}.mp3` 相对地址<br>
**When** 客户端以相对、应用子路径或 CDN 绝对地址配置 `MediaBaseUrl`<br>
**Then** `AudioButton` 将资产地址解析到对应基路径且不重复拼接 `audio/`<br>
**And** 音频清单引用的文件均存在于 `BeafSoup.Blazor.Client/wwwroot/media/audio/` 并随发布产物输出

### 每道题加载后自动播放题目音频

**Given** 当前题的呈现负载提供题目音频（`audioUrl` 或首个 `revealedAudioUrl`）<br>
**When** 该题在课时流程中显示<br>
**Then** 题目音频自动播放一次，同一道题不重复自动播放<br>
**And** 浏览器拒绝自动播放时保持静默，不显示播放失败提示，学习者仍可手动播放

### 判分反馈使用可区分的提示音

**Given** 学习者提交了一道题的答案<br>
**When** 服务端返回判分结果<br>
**Then** 答对与答错分别播放不同的提示音，两者可凭听觉区分<br>
**And** 提示音播放失败或被浏览器禁止时不影响判分结果展示与流程推进

### 音频按钮以图标呈现播放状态

**Given** 页面渲染了音频按钮<br>
**When** 音频空闲或正在播放<br>
**Then** 按钮只显示音频图标，播放状态以呼吸动画表达<br>
**And** 无障碍名称随状态本地化为“播放/播放中”，不在按钮内堆叠冗长文案<br>
**And** 播放失败时才显示本地化错误提示

### 听力题重播真正播放并计数

**Given** 一道 `DialogueListeningMcq` 题已自动播放首行音频，且重播上限为 N<br>
**When** 学习者点击重播按钮且音频开始播放<br>
**Then** 重播计数加一，按钮显示当前次数与上限<br>
**And** 达到上限后按钮禁用，重播不扣红心也不影响判分

### 音频加载或播放失败不产生未处理脚本异常

**Given** 浏览器拒绝播放、音频请求失败或音频元素触发错误<br>
**When** 学习者点击音频播放按钮<br>
**Then** 按钮恢复可用状态并提供本地化失败提示与重试能力<br>
**And** 浏览器控制台不出现未处理的音频 Promise 或 JS 互操作异常

## 内容持久化

### 内容数据持久化往返一致

**Given** 已通过领域校验的概念（含各语言词元与全部范式槽位）、句子（含分词与文本修订号）和课程树<br>
**When** 内容数据写入权威数据库并重新读取<br>
**Then** 概念、词元、范式槽位、标签、句子分词与课程/对话顺序与写入前一致<br>
**And** 词元与范式槽位 Id 跨读写保持稳定（形态掌握度与句子标注可安全引用）

## 账户与使用统计

### 在线用户按服务端租约统计

**Given** 用户 A 有一个或多个由服务端接受的会话心跳，用户 B 的会话租约已过期<br>
**When** 查询在线统计<br>
**Then** 在线用户数只计一次 A，不计 B<br>
**And** 在线会话数按仍有效的不同 `SessionId` 计数

### 断线不会产生无限在线时长

**Given** 一个会话最后有效心跳时间为 T，之后客户端断网或退出<br>
**When** 查询时间超过 `SessionLeaseTtl` 且累计间隔超过最大计时窗口<br>
**Then** 该会话不再计为在线<br>
**And** 服务端不追补超出最大计时窗口的缺失时长

### 服务端不可用时不伪造统计或写入成功

**Given** API/持久化服务不可用<br>
**When** 用户提交学习活动或查询权威在线统计<br>
**Then** 客户端明确报告待重试/不可用状态<br>
**And** 不显示伪造的持久化成功、在线人数或累计时长

## 测试映射

- 领域单元测试：词元跨度、修订失效、复习卡唯一性和 FSRS 评级输入、每语言恰一个主词元、范式槽位 Id 稳定性、名词单词音频带冠词的 TTS 文本规划。
- 持久化集成测试：内容数据 EF Core 往返（含范式槽位 Id 稳定性）、主键/唯一约束、种子入库管线幂等、概念词典 K-V 导出。
- 应用/API 集成测试：身份归属授权（`test/BeafSoup.Api.Tests` 跨用户 404 不泄漏）、幂等活动提交（同 ActivityId 重放不重复计分/扣心）、题型负载版本与六题型判分、统计投影与会话租约、注册重放去重、复习队列与概念卡唯一。
- 浏览器端到端测试：注册后学习流程、逐题显示、各题型判分、翻译排序、输入题手动提交及答对自动推进、账户边界、对话补全音频行为、移动端点词弹层与主题、新账户首次背词自动入队、首页移动端与暗色布局、音频播放失败恢复。
- 客户端单元测试：`test/BeafSoup.Blazor.Tests` 覆盖媒体基路径解析、学习配置并发初始化与失败重试、词典加载重试；`test/Modules/BeafSoup.Audio.Generation.Tests` 校验静态输出目录和清单文件完整性。
