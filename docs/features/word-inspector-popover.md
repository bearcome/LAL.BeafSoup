# 点词弹层（句中单词点击检视器）

> 需求 4 与 6：句子中任意单词/短语——包括各种变格/变位形态——都可点击；弹层显示基础语言解释与形态变化数据，且**绝不改变页面布局**。

## 行为

1. 渲染句子时，按 `SentenceTokenization` 的本地化文本跨度显示原句；词元标注链接到已消歧的 `ParadigmCell` → `Lexeme` → `LexicalConcept`。多词短语使用覆盖在词元序列上的 `SentenceSpanLink`（数据基础见 `model.md`）。
2. 点击/悬停触发（可配置：默认点击固定，悬停仅预览），打开悬浮弹层，锚定于该词元：`position: fixed` 式绝对定位覆盖层，不引发回流——页面滚动/缩放时弹层保持锚定（靠近视口边缘时自动翻转/钳制）。
3. 弹层内容自上而下：
   - 词元 `DisplayWord`（缺省为 `Lemma`）+ 词性 + 冠词 + 发音按钮（单词音频）。
   - **基础语言解释**：取概念词典 K-V 缓存中该概念基础语言的**主词元** `Lemma`（如 `concept.drink` → `喝`；需求 6——纯数据查询，无特殊内容分支）。
   - **常用形态变化**表（可配置，默认：当前槽位 + 最高频 4 个槽位）。
   - 展开/切换至**全部形态变化**表（目标语言主词元的全部范式槽位）——在弹层内展开（可滚动），仍为覆盖层。
   - 1–2 条例句（可播放音频），其中每个词元同样可点击（弹层递归）。
4. 多词短语：支持最长匹配短语链接（短语链接与词元链接并存）。

## 数据供给

- 弹层数据一律来自**概念词典 K-V 缓存**（`localization-data-design.md`）：页面进入时只加载本页句子引用的 concept 条目（全部语言、全部词元、全部范式槽位），客户端以语义 id 内存命中；不得为弹层单独引入服务端往返。

## 可配置项（需求 4"可配置"）

- `defaultInflectionDisplay`：`Common` | `Full`（默认 `Common`）。
- 触发方式：`Click` | `Hover`（默认 `Click`）。
- 存于 `LearnerProfile`，可在设置中修改。

## 不可协商的 UI 约束

弹层不得推挤、换行或改变周边内容尺寸——纯覆盖层；点击外部 / Esc / 路由切换时关闭。第 4 阶段验收包含手工 QA 场景。
