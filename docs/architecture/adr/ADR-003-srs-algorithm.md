# ADR-003：SRS 算法采用 FSRS

- 状态：**提议中**（待所有者确认）
- 日期：2026-11-04

## 背景

需求 2 要求专用背单词模块实现智能记忆法。候选：SM-2（SuperMemo 2，Anki 经典算法）、FSRS（Free Spaced Repetition Scheduler，自由间隔重复调度器）、朴素的 Leitner 盒系统。

## 决策

采用 **FSRS**（开源算法，遗忘曲线建模更优，参数经过充分验证，支持按目标记忆率调参）。

## 后果

- **优点**：在相同记忆率目标下，复习次数明显少于 SM-2；记忆率目标为应用可调参数（先按词书全局，后续支持按学习者）。
- **缺点**：实现略复杂于 SM-2；参数需要随版本更新——通过 `IFsrsParameterProvider` 接口隔离缓解。
- 背词模块按（学习者 × 单词形态）存储调度状态；SM-2 降级方案保留在 `ISrsScheduler` 接口之后，随时可切换。
